# AutoMantenimiento 🚗🔧

Aplicación móvil desarrollada para ayudar a los propietarios de vehículos a llevar un control organizado del mantenimiento preventivo y correctivo de sus automóviles.

---

## 📱 Descripción

AutoMantenimiento es una aplicación diseñada para facilitar el seguimiento de servicios vehiculares, permitiendo a los usuarios registrar mantenimientos realizados, consultar historiales de servicio y recibir recordatorios de futuras intervenciones.

El objetivo principal del proyecto es promover una mejor gestión del mantenimiento automotriz, ayudando a reducir fallas mecánicas y prolongar la vida útil de los vehículos.

---

## 🎯 Objetivos

* Registrar información de vehículos.
* Llevar control de mantenimientos realizados.
* Consultar historial de servicios.
* Gestionar gastos relacionados con el vehículo.
* Mejorar la organización del mantenimiento preventivo.

---

## ✨ Funcionalidades

### Gestión de Vehículos

* Registro de vehículos.
* Edición de información.
* Eliminación de registros.
* Consulta de detalles del vehículo.

### Gestión de Mantenimientos

* Registro de servicios realizados.
* Cambio de aceite.
* Afinaciones.
* Cambio de frenos.
* Revisión de suspensión.
* Servicios personalizados.

### Historial de Servicios

* Consulta cronológica de mantenimientos.
* Registro de fechas.
* Kilometraje del vehículo.
* Observaciones del servicio.

### Control de Gastos

* Registro de costos por mantenimiento.
* Seguimiento de gastos acumulados.
* Consulta de historial financiero.

### Recordatorios

* Próximos servicios programados.
* Alertas según kilometraje.
* Seguimiento preventivo.

## 🚀 Instalación

### Clonar repositorio


### Abrir proyecto

1. Abrir Android Studio.
2. Seleccionar Open Project.
3. Elegir la carpeta del proyecto.

5. Ejecutar en un dispositivo físico o emulador Android.
